## 근본 원인 관점

직전 결함의 일부는 화면 구성 문제가 아니라 상태 인계와 외부 생성 의존성 문제였다. PR #134는 캔버스 편집기와 레이아웃, 컷 미리보기처럼 프론트에서 닫을 수 있는 결함을 고쳤다. 그러나 생성 서비스 HTTP 503과 `기존 실제 이미지가 생성실에는 보이지만 카드 편집실에는 0개`인 상태 경계는 남았다. 따라서 화면 개선을 전체 생성·편집·발행 복구로 확대 해석하면 안 된다.

다음 수정의 단일 종료 증거는 `새 이미지·영상 각 1건 HTTP 2xx → 새 작업물 두 썸네일 → 같은 초안 카드·영상 편집실 첫 화면 실제 미디어 → 컷·드래그 반영 → 내보내기 → 같은 초안 발행실 이미지·영상`을 하나의 운영 E2E로 통과시키는 것이다.

셀프심문: 이 결론이 틀렸다면 가장 그럴듯한 이유는 기존 영상·이미지로 확인한 하류 개선을 신규 생성 E2E 성공으로 오인하는 것이다. 그래서 신규 생성은 503 NG, 기존 미디어 하류는 별도 회귀 신호로 분리했다.
