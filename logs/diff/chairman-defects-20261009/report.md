## 왜 기존 QA가 통과처럼 보였나

기존 검증은 내보내기 시간, 화면 전환, 가로 넘침, 콘솔 오류 같은 대리지표에 집중했다. `생성 → 생성실에 결과 표시 → 편집실에 미디어 인계 → 편집 조작이 미리보기에 반영 → 실제 미디어가 든 발행 미리보기`라는 회장 사용 경로를 하나의 왕복으로 돌리지 않았다. 또한 승인 디자인 핀 v68과 이번 비교 대상 v71의 불일치를 해소하지 않은 채 디자인 QA 증거가 분리돼 있었다.

재발 방지 수용기준은 다음 네 개를 한 E2E로 묶는 것이다.

1. 실제 이미지·영상 생성 뒤 작업물 목록에 썸네일과 상태가 보인다.
2. 같은 초안의 카드·영상 편집실에 해당 미디어가 첫 화면에서 보인다.
3. 텍스트 드래그와 영상 컷 조작 뒤 미리보기 픽셀·재생 시간이 바뀐다.
4. 발행실 각 플랫폼 미리보기에 실제 이미지·영상이 표시되고, 외부 발행 직전까지 왕복한다.
