# Genspark 경쟁 분석 v1.0

> 한 줄 결론: **Genspark 는 우리 정면 경쟁자가 아니라 상류 인접재다. 우리를 죽일 수 있는 경로는 딱 하나, 저쪽이 소셜 발행 커넥터를 붙이는 순간이다.**

이 문서는 사업계획 v1.4 §2 가 조사한 55곳 목록에 Genspark 가 빠져 있어 보완한 것이다. 기존 경쟁 판정을 뒤집지 않는다.

## 1. Genspark 실체

### 1.1 무엇을 파는가

**결과물을 만들어 주는 범용 AI 작업 공간이다.** 채팅으로 지시하면 자율 에이전트가 계획을 세우고 도구를 골라 문서·슬라이드·표·영상·오디오·전화까지 처리한다. 특정 직무 전용 도구가 아니라 "AI 직원 한 명"을 파는 포지션이다.

플랫폼 구조는 9개 대형 언어 모델과 80개 이상 도구를 물려 놓고, 과업마다 가장 맞는 것을 자동 배정하는 방식이다.

### 1.2 확인된 핵심 기능

| 기능 | 무엇을 하는가 | 확인 |
|---|---|---|
| **Super Agent** | 스스로 계획하고 실행하는 자율 에이전트. 2025년 4월 출시. 전화·슬라이드·영상 생성까지 무코드로 수행 | 확인 |
| **AI Slides** | 프롬프트를 구조화된 발표자료로. 사실 검증 계층이 붙어 있음 | 확인 |
| **AI Sheets** | 정보를 수집해 표와 요약으로 구조화 | 확인 |
| **AI Docs** | 프롬프트와 템플릿으로 문서 초안 작성 | 확인 |
| **Call For Me** | 실제 전화를 걸어 대화하고 통화록과 요약을 반환. OpenAI Realtime API 기반 | 확인 |
| **AI Pods** | 주제·영상주소·파일을 넣으면 2인 대담 팟캐스트 오디오를 생성. NotebookLM 대응물이며 자체 조사까지 함. 슬라이드를 얹은 영상 팟캐스트와 AI DJ 모드도 있음 | 확인 |
| **연결 앱** | Gmail·Drive·캘린더·Slack·Notion·HubSpot, 그리고 MCP 서버로 임의 확장. CLI(`gsk connector list`)로 연결 목록 조회 | 확인 |
| **공유** | 결과물을 로그인 없이 열리는 공개 링크로 배포 | 확인 |
| **소셜 채널 직접 발행** | **없다** (§3.2에서 판정 근거) | 확인된 범위에서 없음 |

### 1.3 타겟 고객

지식 노동 전반이다. 특정 직무를 좁혀 팔지 않는다. 요금제 구성이 개인($24.99) → 고급 개인($249.99) → 팀(자리당 $30, 2~150명) → 기업(150명 초과, 데이터 소재지 설정·99.9% 가동률 보장)으로 개인부터 기업까지 통으로 덮는다.

### 1.4 성장 지표

| 시점 | 값 | 출처 |
|---|---|---|
| 5개월 | 연환산 매출 5천만 달러 | ARR Club |
| 9개월 (2026-01-19 발표) | 연환산 매출 1억 달러 | blockchain.news |
| 10개월 | 1억 5,500만 달러 | ARR Club |
| 12개월 (2026-06 투자 발표 시점) | 약 2억 5천만 달러 | ARR Club / Latka |
| 2026-06-17 | 시리즈B 연장 1억 달러, 기업가치 26억 달러, 누적 조달 5억 3,500만 달러 | TIGI |
| 현재 | 월 활성 사용자 200만 명 이상, 유료 좌석 추정 10만 개 | Latka |

유료 좌석 10만 개는 3자 추정치다. 회사 공식 발표가 아니므로 그대로 인용하지 않는다.

**이 숫자가 우리에게 뜻하는 것**: "범용 에이전트가 결과물을 만들어 준다"는 약속에 시장이 1년 만에 2억 5천만 달러를 지불했다. 만들기 자체는 이미 값이 매겨졌고 빠르게 흔한 것이 되고 있다는 뜻이다. 우리 값은 만들기가 아니라 그다음에 있어야 한다.

## 2. 가격과 크레딧 모델

| 요금제 | 월 | 연납 환산 | 크레딧 | 저장 공간 |
|---|---|---|---|---|
| 무료 | $0 | | 하루 100 | 미공개 |
| Plus | $24.99 | $19.99 | 월 10,000 | 50GB |
| Pro | $249.99 | $199.99 | 월 125,000 | 1TB |
| 팀 | 자리당 $30 | | 자리당 12,000 | 자리당 60GB |
| 기업 | 별도 협의 | | 자리당 25,000 이상 | 별도 |

**크레딧 규칙에서 배울 점과 경계할 점**

- 채팅과 이미지 생성은 유료 요금제에서 **크레딧 0**이다. 단 2026-12-31까지의 한시 판촉이다.
- 크레딧을 많이 먹는 것은 영상 제작, 음성 내레이션, 고해상도 이미지, 긴 콘텐츠다. 즉 **원가가 큰 것에만 계량기를 단다.**
- 유료 요금제(Plus·Pro)의 생성물 상업적 이용 권리도 2026-12-31까지만 보장한다고 표기돼 있다.
- 크레딧은 이월되지 않는다. "무제한 채팅"에도 5시간 상한이 숨어 있다.
- 재생성은 원본과 같은 값을 물린다. 자동 선택 모드는 여러 판본을 만들고 각각 과금한다.
- 비로그인 상태로 요금 페이지를 열면 로그인 화면으로 튕긴다.

뒤의 다섯 줄은 우리가 **따라 하면 안 되는 것**이다. 이월 없음·숨은 상한·재생성 과금·로그인 뒤 가격은 마케팅 품질헌법 §4의 기망 하드라인에 걸린다. 특히 "무제한"이라 쓰고 5시간 상한을 두는 것은 거짓 정보 금지 위반이다. 우리 요금 표기에 절대 이식하지 않는다.

## 3. 우리와 겹치는 면과 안 겹치는 면

### 3.1 대조표

| 항목 | Genspark | OSMU | 판정 |
|---|---|---|---|
| 콘텐츠 초안 생성 | 문서·슬라이드·표·영상·오디오 전방위 | 글·사진카드·영상 세 형식 | **겹침**. 저쪽이 넓다 |
| 브랜드 근거를 사람이 확정하고 줄 단위로 관리 | 미확인. 브랜드 가이드 계층을 공개 자료에서 확인 못 함 | 학습 정보 7계층, 한 줄 단위 켜기 끄기 | **안 겹침(우리 우위, 단 미확인 근거)** |
| 채널 계정 연결(OAuth) | 없음. 연결 대상은 Gmail·Drive·Slack·Notion·HubSpot 등 업무 도구 | Threads·Instagram·X·YouTube·TikTok·LinkedIn 계정 연결 | **안 겹침. 여기가 경계선** |
| 하나 만들어 여러 채널 동시 발행 | **없다** | 제품의 한 문장 그 자체 | **안 겹침** |
| 예약 발행과 중복 발행 방지 | 없음 | 정확히 한 번 실행, 발행 증거 회수 | **안 겹침** |
| 승인 절차(사람이 검수 후 발행) | 해당 없음 | 승인 정책·승인 요청·예약 승인 | **안 겹침** |
| 발행 후 성과 수집과 다음 실험 | 없음 | 성과실, 승인된 변수 하나만 반영 | **안 겹침** |
| 결과물 배포 방식 | 로그인 없이 열리는 공개 링크 | 채널 원문 게시 | 성격이 다름 |
| 과금 단위 | 크레딧(생성량) | 캠페인 운영 결과. 게시물 수 단독 과금은 금지 | **철학이 반대** |
| 자율성 | 높음. 알아서 계획하고 실행 | 낮음. 사람이 승인하는 구간이 명시적 | 의도된 차이 |

### 3.2 "콘텐츠 하나 → 다채널 발행"이 Genspark 에 있는가

**없다고 판정한다. 근거 셋이다.**

1. 공개된 연결 앱 목록에 소셜 플랫폼이 하나도 없다. Gmail·Drive·캘린더·Slack·Notion·HubSpot과 MCP 확장이 전부다.
2. 2026년 소셜 예약 도구 비교 기사군(Sprout Social 21선, PostQuick 비교, digitalapplied 비교)에 Genspark 가 등장하지 않는다. 그 범주로 팔지 않는다는 뜻이다.
3. 발행 계층 업체(Blotato)가 시장을 설명하는 문장이 이렇다. "어떤 AI 에이전트도 스스로 게시하지 못한다. 그래서 각각 아래에 Blotato 같은 발행 계층이 필요하다." 에이전트에는 소셜 계정도 OAuth 토큰도 없어서, 게시 API를 부르거나 게시를 도구로 노출하는 MCP 서버를 거쳐야만 한다.

**단 한계를 명시한다.** genspark.ai 본사이트와 공식 블로그가 403으로 막혀 1차 자료를 못 봤다. 사용자가 소셜 게시용 MCP 서버를 직접 붙이면 기술적으로는 게시가 가능하다. 다만 그것은 제품이 파는 기능이 아니라 사용자가 조립하는 것이고, 1인 사업가가 넘을 수 있는 문턱이 아니다.

### 3.3 그래서 이게 우리 해자인가

**절반만 해자다. 정확히 말하면 "지금은 해자, 구조적으로는 아니다."**

해자인 이유는 발행 계층이 기능이 아니라 **누적 자산**이라서다. 채널마다 심사를 통과해야 하고(우리가 Meta App Review에서 겪는 그것), 계정별 OAuth 토큰을 안전하게 보관해야 하고, 채널별 규격 차이와 실패 복구를 다 알아야 한다. 이건 모델 성능으로 뛰어넘는 종류가 아니다. 시간과 심사가 든다.

해자가 아닌 이유는 **살 수 있어서다.** Genspark 가 발행 계층 업체를 인수하거나 커넥터를 만들면 몇 달이면 붙는다. 2억 5천만 달러 연환산 매출과 5억 달러 조달금이면 살 수 있다.

**결론: 발행 계층 단독은 해자가 아니다. 해자가 되는 것은 "발행 증거가 성과로 돌아와 브랜드 규칙을 한 줄씩 고치는 순환"이다.** 그건 고객 계정에 시간이 쌓여야 생기는 것이라 돈으로 못 산다. 우리 판매 문구의 무게중심을 발행이 아니라 이 순환에 두어야 한다.

## 4. 훔칠 것 세 가지

훔치는 것은 구조와 심리 장치이고, 문구와 브랜드 자산은 훔치지 않는다.

### 4.1 원가 있는 것에만 계량기를 단다 (가격 표현)

**무엇**: 채팅과 이미지 생성은 크레딧 0, 영상·음성·고해상도만 크레딧 차감. 사용자는 "생각하는 건 공짜, 무거운 것만 돈"으로 이해한다.

**우리 이식안**: 글 초안 생성과 편집실 왕복은 요금제 안에서 무제한, 영상 생성만 건별 승인 관문(D-014)에 태운다. 지금 우리 구조가 이미 그렇게 되어 있으니 **가격 표현만 바꾸면 된다.** "월 N건" 대신 "글은 무제한, 영상만 건별 확인".

**왜 1인 사업가에게 통하나**: 이 고객의 1번 공포는 "쓰다가 얼마 나올지 모른다"는 것이다. 손실회피가 사용 단계(②)의 활성화를 막는 주된 마찰이다(BRAIN 유저심리 6단계 정본 ② 사용 단계, 기본값 편향·손실회피). 무거운 것만 계량기를 달면 나머지 구간에서 손실회피가 꺼진다.

**단, 세 가지는 안 훔친다**: 크레딧 이월 없음, 숨은 5시간 상한, 재생성 동일 과금. 기망 하드라인이다.

### 4.2 결과물 공개 링크를 발행 앞단에 끼운다 (화면·바이럴)

**무엇**: Genspark 는 만든 것을 로그인 없이 열리는 링크로 즉시 공유한다.

**우리 이식안**: 편집실 검수 완료 시 "이 캠페인 미리보기 링크" 버튼 하나. 발행 전에 동업자나 배우자에게 던져 확인받는 용도이자, 그 링크 하단에 조용한 제작 표기가 붙는다.

**왜 1인 사업가에게 통하나**: 이 고객은 팀이 없어서 자기 판단을 검증할 상대가 없다. 승인받을 사람이 없다는 것이 발행 직전에 손이 멈추는 진짜 이유다. 그리고 공유 장벽 관점에서 이건 "요청"이 아니라 "선언"이다. 자기가 만든 결과물을 보여주는 것은 체면 비용이 없다(BRAIN 공유장벽 선언 대 요청 UGC 바이럴). ④ 바이럴 단계 장치다.

**주의**: 우리 D-014·ADR-007 정합. 링크는 조용히 실패하면 안 되고 만료·권한 상태를 화면에서 말해야 한다.

### 4.3 자율 에이전트의 실행 계획을 눈에 보이게 편다 (에이전트 UX)

**무엇**: Super Agent 는 지시를 받으면 계획을 세우고 도구를 골라 단계적으로 실행하며, 그 과정이 사용자에게 보인다.

**우리 이식안**: 생성실에서 요청을 넣으면 즉시 결과가 아니라 **실행 계획을 먼저 카드로 편다.** "①브랜드 규칙 12줄 적용 ②Threads용 초안 ③Instagram 카드 4장 ④검수 대기". 각 줄은 실행 전에 끌 수 있다.

**왜 1인 사업가에게 통하나**: 우리 한 문장이 "통제권은 주되 어려운 부분은 대신한다"인데, 통제권은 결과물이 아니라 **과정이 보일 때** 체감된다. 결과만 툭 나오면 좋아도 못 믿고, 나쁘면 어디를 고쳐야 할지 모른다. 계획을 먼저 보여주면 커밋먼트 심리(자기가 승인한 계획은 결과도 자기 것)가 붙고, ADR-007의 "못 하면 이유를 말한다"가 실패 시점이 아니라 시작 시점에 앞당겨진다.

**세 가지 중 하나만 고른다면 4.3이다.** 4.1은 표현 변경이고 4.2는 부가 기능이지만 4.3은 우리 제품 한 문장의 증명이다.

## 5. 위협 판정과 사전 부검

### 5.1 판정: 인접재다. 단 상류 인접재다

정면 경쟁자가 아니다. 고객이 Genspark 와 우리 중 하나를 고르는 상황이 아니라 **둘 다 쓰는** 상황이 자연스럽다. 만들기는 저쪽, 계정에 올리고 성과를 회수하는 것은 우리다.

위험한 것은 이것이 **상류**라는 점이다. 고객이 만드는 곳에서 이미 지갑을 열고 있다. 상류가 하류로 내려오는 것은 쉽고, 하류가 상류로 올라가는 것은 어렵다. 우리는 생성 품질로 Genspark 를 이길 수 없다. 시도해서도 안 된다.

같은 이유로 사업계획 §2.2에서 이미 잡은 Simplified(12채널 직접 발행, 월 59달러)와 Ocoya(월 15달러)가 우리에게는 Genspark 보다 더 급한 정면 상대다. 그 판정은 유지된다.

### 5.2 사전 부검: 1년 뒤 우리가 밀렸다면

1. **Genspark 가 소셜 커넥터를 붙였다.** 발행 계층 업체를 인수하거나 자체 구축해 "만들고 바로 올린다"를 한 화면에 넣는다. 우리 차별 문구가 그날 사라지고, 월 25달러에 전방위 생성까지 얹은 쪽에 가격으로도 진다.
2. **우리가 발행을 팔다가 졌다.** "다채널 동시 발행"만 외치는 사이 그것이 월 15달러짜리 흔한 기능이 되고, 우리가 진짜 못 살 자산으로 만들려던 성과 되먹임 순환은 고객 계정에 데이터가 안 쌓여 작동하지 않는다. 판매 문구와 실제 해자가 어긋난 채로 1년을 보낸 것이 사인이다.
3. **채널 심사에서 시간을 잃었다.** Meta App Review 같은 관문에 반년을 쓰는 동안, 심사가 필요 없는 생성 도구는 매달 기능을 냈다. 우리 진입장벽이 우리를 먼저 막았다.

**세 경로 모두에 듣는 한 가지 대비**: 판매의 무게중심을 지금 발행에서 성과 되먹임으로 옮긴다. 발행은 전제이지 값이 아니다.

## 8. 회장이 정할 것

⛔ 회수 필요: 판매 문구의 무게중심을 발행에서 성과 되먹임으로 옮길 것인가

- 배경: Genspark 조사 결과 "만들기"는 이미 1년 만에 2억 5천만 달러가 매겨진 흔한 것이 되었고, "다채널 발행"은 Ocoya 월 15달러·Simplified 월 59달러가 이미 판다. 우리가 유일하게 못 복제당하는 것은 발행 증거가 성과로 돌아와 브랜드 규칙을 한 줄씩 고치는 순환인데, 지금 우리 한 문장과 랜딩은 발행을 앞에 세우고 있다.
- 무엇을 정하나: 대외 판매 문구의 1번 자리에 무엇을 둘 것인가.
- 옵션 A(추천): 성과 되먹임을 1번, 다채널 발행을 전제로 강등. 고르면 Genspark 가 커넥터를 붙여도 우리 문구가 안 죽는다. 안 고르면 저쪽이 발행을 붙이는 날 차별점이 하루 만에 증발한다.
- 옵션 B: 지금대로 발행을 1번 유지. 고르면 지금 고객에게 설명하기 쉽고 즉시 이해된다. 트레이드오프: 월 15달러 올인원과 같은 축에서 가격 경쟁에 끌려간다.
- 추천 근거: 사업계획 §2.2가 이미 "가격 하한이 눌려 있다. 생성과 발행을 묶은 올인원이 월 15달러부터 있다"를 도전 과제로 적어 두었다. 발행 축에서 이기는 그림이 문서 자체에 없다. 반면 성과 되먹임은 우리 One Thing("적격한 결과에서 승인된 변수 하나만 다음 실험에 반영")에 이미 박혀 있어 새로 만들 것이 없고 문구만 앞으로 당기면 된다.
