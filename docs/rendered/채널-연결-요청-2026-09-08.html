2026-09-08 00시 30분 기준
구조 확인. 사파리에 켜져 있는 j.the.great.investor@gmail.com 은 고객 계정입니다. 고객은 OAuth 로그인 한 번이면 발행까지 가야 하고, 개발자 콘솔에 들어갈 일이 없어야 합니다. 아래는 전부 관리자(회장님) 쪽 앱 등록 작업입니다. 이것이 한 번 서면 이후 가입하는 고객은 단추만 누르면 됩니다.

지금 막고 있는 것 (관리자 조치)

1. 유튜브 — 고객 계정에 유튜브 채널이 없음
동의와 토큰 교환까지 전부 통과했고, 마지막 채널 조회에서 목록이 비어 실패합니다. 즉 앱 설정 문제가 아니라 그 구글 계정에 유튜브 채널이 없는 것입니다. 화면 문구도 "다시 연결"만 시키고 있어서 방금 원인을 말하도록 고쳤습니다.
고객 계정으로 유튜브 채널 만들기 구글 동의 화면(앱 심사)
채널을 만드시면 제가 바로 연결까지 끝냅니다. 참고로 구글은 아직 "확인하지 않은 앱" 경고가 뜨며, 외부 고객에게 열려면 앱 심사가 필요합니다.
2. 인스타그램 — Instagram 전용 앱 시크릿 확인
동의까지 통과한 뒤 장기 토큰 교환에서 막힙니다. 이 앱은 Instagram 전용 시크릿이 Meta 앱 시크릿과 별개인데, 서버에 넣어둔 값이 어느 쪽인지 확인이 필요합니다. 시크릿을 보려면 비밀번호 재인증이 걸려 제가 못 봅니다.
Instagram API 설정 바로가기
값은 보내지 마시고 서버 값과 "같다·다르다"만 알려 주십시오. 다르면 교체는 제가 합니다.
3. 페이스북 — 관리 중인 페이스북 페이지가 없음
OAuth는 통과했는데 페이지 목록이 비어 실패합니다. 페이스북은 개인 계정이 아니라 페이지에 글을 올립니다. 페이지 생성은 대외에 노출되는 브랜드 결정이라 제가 임의로 만들지 않았습니다.
페이스북 페이지 만들기
만드신 뒤 알려 주시면 연결은 제가 끝냅니다.
4. X — 사용 요금 소진
연결·인증·토큰 자동 갱신까지 전부 정상입니다. 오늘 밤 토큰이 만료됐는데 자동 갱신이 되살려 X까지 요청이 갔고, 거기서 요금 소진으로 막혔습니다. 돈이 나가는 일이라 제가 하지 않습니다.
X 개발자 콘솔
5. 틱톡·링크드인 — 앱 미등록
틱톡은 발행 기능이 이미 있습니다. 앱 등록만 하면 됩니다. 링크드인은 발행 기능도 없어 새로 지어야 하고 회사 페이지 이름이 필요합니다.
틱톡 개발자 앱 링크드인 개발자 앱
지금 붙일지, 인스타그램이 열린 뒤에 할지 알려 주십시오. 추천은 인스타그램 먼저입니다. 사업계획 페르소나에 실명으로 나오는 채널이 인스타그램 하나뿐입니다.
