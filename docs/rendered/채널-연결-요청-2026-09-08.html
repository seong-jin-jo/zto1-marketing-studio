채널 연결 · 회장님 손이 필요한 것만

2026-09-08 00시 기준. 제가 할 수 있는 것은 전부 했고, 아래 넷은 제 권한 밖입니다.
1. 맥 잠금 해제 (가장 급함)
지금 로그인 화면이라 화면을 눌러야 하는 작업이 전부 멈춰 있습니다. Facebook 연결 팝업의 페이지 선택, Meta 콘솔 조작이 여기 걸려 있습니다. 비밀번호 입력은 제가 할 수 없습니다.
잠금만 풀어 주시면 Facebook 연결은 제가 끝냅니다.
2. 인스타그램 앱 시크릿이 서버 값과 같은지
인스타그램은 동의까지 통과한 뒤 마지막 장기 토큰 교환에서 실패합니다. 이 앱은 Instagram 전용 시크릿이 Meta 앱 시크릿과 별개인데, 서버에 넣어둔 것이 어느 쪽인지 확인이 필요합니다. Meta가 시크릿을 보여줄 때 비밀번호 재인증을 요구해 제가 못 봅니다.
  1. developers.facebook.com 접속
  2. 앱 정성컴퍼니 선택
  3. 왼쪽에서 Instagram → API setup with Instagram login
  4. Instagram 앱 시크릿 코드 옆 표시 클릭 (비밀번호 재인증)
값은 저에게 보내지 마십시오. 서버 값과 "같다" 또는 "다르다"만 알려 주시면 됩니다. 다르면 교체는 제가 합니다.
3. X 크레딧 충전
연결과 인증은 살아 있습니다. 방금 시험했을 때 토큰이 만료돼 있었는데 자동 갱신이 되살려 X까지 요청이 갔고, 거기서 요금 소진으로 막혔습니다. 돈이 나가는 일이라 제가 하지 않습니다.
X 개발자 콘솔에서 충전하시면 그 즉시 발행됩니다.
4. 유튜브·틱톡·링크드인 계정 방향
유튜브와 틱톡은 발행 기능이 이미 있습니다. 계정만 연결하면 됩니다. 링크드인만 기능이 없어 새로 지어야 하고, 회사 페이지 이름이 필요합니다.
지금 붙일지, 인스타그램이 열린 뒤에 할지 알려 주십시오. 추천은 인스타그램 먼저입니다. 사업계획의 페르소나에 실명으로 나오는 채널이 인스타그램 하나뿐입니다.
