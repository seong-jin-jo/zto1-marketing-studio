## 벤치마크 적용

Next.js 공식 Route Handler 문서에서 GET과 HEAD가 별도 지원 메서드임을 차용해 메서드별 실행 분모를 만들었다. RFC 9110에서 2xx, 3xx, 4xx, 5xx 의미를 차용해 3xx를 정상에서 제외했다. 제품 계약상 준비되지 않음 503처럼 의도된 거절은 코드와 정확한 기대 상태를 함께 등록해 일반 5xx와 구분했다.

- Next.js Route Handlers: https://nextjs.org/docs/app/getting-started/route-handlers
- RFC 9110: https://www.rfc-editor.org/rfc/rfc9110.html
