OSMU STUDIO · 생성실 + 편집실 · 품질 기준선

지금 나가는 카드는 디자인이 못난 게 아니라, 콘텐츠 구조가 없다.

회장이 지목한 기준(D-EDU 카드컨셉13 D-100)과 현재 OSMU 산출물을 같은 자로 재면, 아홉 축 중 일곱이 0점이다. 색·서체 문제가 아니다. 후킹 표지, 실사 배경, 대화 구조, 장수, 댓글 CTA, 숏폼 댓글 반응, 재생 가능한 미리보기가 통째로 빠졌다. 편집실은 "글자 위치 상·중·하"만 만질 수 있어서 이 결손을 사용자가 메울 길도 없다.

"생성실에서 생성한 컨텐츠 퀄리티는 왜 개쓰레기 수준이고 편집은 UX 가 쓰레기 수준이냐. 이 정도로 만들어야겠다는 컨텐츠 레퍼런스 가져와라. 영상에서 시청자 댓글 반응 같은 거 삽입하는 거 아니냐. 영상 편집에는 재생도 안 된다. 카드뉴스는 디에듀에서 작업한 D-100, 90, 80 카드뉴스 편집 같은 거 참고해라." 회장 2026-09-21 원문 요지 · 발행 실물: instagram.com/p/Ddh5IvAHyFg · x.com/i/web/status/2101833562949599524

  • 편집실이 레퍼런스 에디터 대비 없는 기능과 최소 기능 6개 (§3)

  • 숏폼 "시청자 댓글 반응 삽입" 편집 화면 와이어 1장 (§5)

이 문서가 안 하는 것

  • 새 디자인 시스템. DESIGN.md v37 토큰만 쓴다
  • 발행실·성과실. 이번 지목은 생성실·편집실이다
  • 실사 이미지 생성 엔진 선정(힉스필드 자격증명은 이미 배선됨, 실수.md 2026-09-10). 배경 "출처"는 §4에서 선택지로만 둔다

"이 정도는 돼야 한다": 형식별 레퍼런스 실물

표지
풀블리드 실사(캠퍼스) + 하단 40% 어두운 스크림 + 흰색 볼드 헤드라인 3줄 좌하단 + @핸들. 상단 텍스트 0. 스크롤 정지력의 근원
헤드라인
"안 오르는 건 머리가 아니라 순서입니다." 고통 인식형 단정. 자책을 멈추게 해 다음 장을 넘기게 한다
본문 구조
실제 카톡 UI. 독자(나) = 우측 노랑, 멘토 = 좌측 흰색 + 프로필 + 이름 + 시각. "내가 멘토와 채팅 중" 몰입
리듬
장마다 질문 → 답. open loop 로 완독률 방어. 한 장에 주장 하나, 굵은 글씨는 한 장에 한 덩이
신뢰 장치
"12년간 300명 상담" 팩트락 + 하단 "실적: 회장 제공 자체 집계 기준" 각주. 근거 없는 숫자 0
브랜드 시그니처
같은 배경 톤, 같은 제목 위치, 같은 @핸들 위치, 페이지 번호 02/11. 9칸 피드에서 한 시리즈로 읽힌다
CTA
링크 대신 "댓글에 '순서' 남겨줘, DM 으로 보내줄게" + 댓글 예시 칩 + "저장해두고 D-90 에 다시 펴봐" 저장 명분. 댓글·저장 알고리즘 신호를 한 장에

심리 근거(BRAIN 유저심리 6단계): 관심=고통 인식 훅+후광(캠퍼스), 사용=상호성(무료 순서 짚기), 반응=자이가르닉(open loop), 바이럴=저장 명분. 윤리 1선: 실제 대학 로고는 워터마크로만 열망 배경, 제휴 암시 없음.

② 재생 불가 원인을 코드 구조로만 읽었다. 실제 원인이 previewVideoUrl 이 null(asset_url pending:render) 일 수도 있다. 둘 다 고쳐야 하므로 로드맵은 안 바뀐다.
③ 0번 게이트: design-html 을 실제 호출해 골격을 잡았고 design-review 는 출고 전 호출한다(STAMP 바 등급). design-consultation·design-shotgun 은 DESIGN.md 가 있고 방향 재설정이 아니라 건너뛰었다. 이 문서는 후보군 산출이 아니라 기준 문서라 §1-12 단일안 금지 조항의 대상이 아니라고 판단했다. 이 판단이 틀렸다면 §5 시안을 3안으로 벌려야 한다.
레드팀(회의적 고객): "결국 캔바 템플릿 베끼기 아니냐"
캔바는 빈 캔버스에 예쁜 틀을 주고 글은 사용자가 쓴다. OSMU 는 학습 정보(브랜드·실적·톤)로 글을 먼저 만들고, 그 글이 D-100 처럼 "대화 구조" 로 나온다는 것이 차이다. 캔바 사용자는 9장짜리 대화를 직접 써야 하고, OSMU 사용자는 말풍선 하나를 고친다. 그래서 갭표의 첫 축을 색이 아니라 ①훅 ③대화 구조로 두었다. 이 차별화가 안 보이면 이 문서는 실패다.

⛔ 회수 필요: 표지 실사 배경의 출처를 무엇으로 두나

배경: 갭 ② 를 닫으려면 표지에 사진이 있어야 한다. 생성 엔진(힉스필드) 자격증명은 배선돼 있으나 건당 비용이 나가고(D-014 승인 관문), 사용자 업로드는 비용 0 이지만 자영업자가 쓸 만한 사진이 없는 경우가 많다.

무엇을 정하나: 2단계 배경 레이어의 기본값.

  • 옵션 A(추천): 기본 = 학습 정보에 등록한 브랜드 사진 → 없으면 업로드 → 원하면 생성(승인 관문). 고르면: 비용 0 으로 시작, 생성은 선택. 안 고르면: 사진 없는 워크스페이스는 단색 표지가 계속 나간다.
  • 옵션 B: 기본 = 생성. 고르면: 모든 표지가 즉시 실사. 트레이드오프: 건당 비용, 생성 실패 시 표지가 비는 경로가 생긴다(ADR-007 대로 이유를 말해야 함).
