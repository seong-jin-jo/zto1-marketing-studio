- 말풍선 합계 높이가 카드 높이를 넘으면 **자동으로 다음 장으로 넘긴다.** 글자를 줄여서 우겨 넣지 않는다.
- 넘어간 사실을 카드 아래 한 줄로 알린다: "이 장은 2장으로 나뉩니다".
- 한 장의 말풍선 상한은 두지 않는다. 장 수 상한(11장)이 먼저 걸린다.

## 5. 음악 형식 제거

| 항목 | 값 |
|---|---|
| 형식 탭 | 4 → **3** |
| 제거 위치 | `EDIT_KIND_ORDER` 의 `audio` |
| 데이터 | **지우지 않는다.** 기존 audio 초안은 보존, 화면에서만 내린다 |
| 목소리 | 영상 편집기 조작 줄로 흡수 (`video-edit-contract.ts` `voice` 에 이미 자리가 있다) |
| 생성실 영향 | 형식 고르기에서 "배경 음악" 칸 제거 |
| 발행실·성과실 영향 | **0.** 원래 audio 를 안 받는다 |

제거 근거 3건(전부 `origin/main` 코드 실측):
1. 생성 경로 0. 편집실 audio 분기가 화면에 직접 적어 뒀다 — "음악 파일 생성은 아직 제공하지 않습니다".
2. 발행 채널 0. `platform-publish-fields.ts` 와 발행 라우트에 `audio` 분기가 없다. 연결 7채널 중 오디오 단독 게시를 받는 곳이 없다.
3. 편집 화면은 빈 회색 상자 + 경고문 한 줄. 조작 요소 3개(목소리·음악·음량)의 값이 어디에도 안 쓰인다.

## 6. 상태 5종 + 넘침

| 상태 | 글 | 카드뉴스 | 영상 |
|---|---|---|---|
| **빈** | 생성실로 가는 단추 1개 | 동일 | 동일 (R-25-1: "영상 없음"으로 끝내지 않는다) |
| **로딩** | 문단 스켈레톤 9줄 | **진행률 "3 / 9장"** + 막대 + "장당 최대 8초" 고지 | 플레이어 스피너 + 대본 스켈레톤 |
| **실패** | 저장 막힘. "쓴 글이 사라지지 않았다"를 맨 앞에 | 사진 주소 만료. 발행 차단 사실 + 빠져나갈 길 2개 | 영상 주소 만료. "편집 내용은 살아 있다" 먼저 |
| **저장됨** | 점 녹색 + "방금 저장됨" | 동일 | 동일 |
| **편집 중** | 점 주황 펄스 + "자동 저장 중" | 동일 | 동일 |
| **넘침** | 상한 초과 칩 red + "발행실에서 채널별로 줄인다" | 말풍선이 카드 높이 초과 → 다음 장 자동 분할 | 자막 36줄 → 대본 스크롤, 타임라인 5초 묶음 |

**실패 화면 규격 (ADR-007).** 세 요소 필수: ①무엇이 없어서 못 하나 ②지금까지 한 것이 어떻게 됐나 ③빠져나갈 길 단추 최소 1개. 셋 중 하나라도 빠지면 그 화면은 미완이다.

## 7. 모션

| 이름 | duration | easing | 언제 | 왜 |
|---|---|---|---|---|
| 저장 중 점 | 1200ms 반복 | `--ease` | 자동 저장 진행 중 | 저장 여부를 상시로 알려 "날아갈까" 불안을 닫는다 |
| 로딩 스피너 | 800ms 반복 | linear | 로딩 | 표준 |
| 스켈레톤 | 1300ms 반복 | linear | 로딩 | 실제 내용 모양과 같은 자리에 |
| 탭·칩 전이 | 120ms (`--fast`) | `--ease` | hover·선택 | 즉각 반응 |
| 재생 위치 | 프레임마다 (`requestAnimationFrame`) | 없음 | 재생 중 | **숫자가 변하는 연출은 세는 로직까지 넣는다** (standard-design.md §11.1) |
| 카드 미리보기 갱신 | 없음 (즉시) | 없음 | 편집 중 | 현행 300ms 디바운스를 **없앤다**. DOM 편집은 지연이 필요 없다 |

`prefers-reduced-motion` 존중. `transition: all` 금지 (실제 변하는 속성만 열거).

## 10. 미검증으로 남기는 것

- 실제 조작 시간과 타건 재현. 클릭 수는 코드에서 센 값이다(근거 확인). 사람이 실제로 얼마나 빨라지는지는 **미검증**.
