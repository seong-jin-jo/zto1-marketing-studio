# 편집실 v2, v71 시안 대비 현재 구현 차이표

> 결론: 회장에게 보여 준 v71은 목표 시안이고, 현재 코드는 v70 기반 편집기에 영상 재서명, 영상 컷·오버레이 렌더, Remotion 인트로·아웃트로를 증분한 상태다. 특히 사진·글 카드 자유 배치, 통합 내보내기 화면, 영상 5레인은 아직 구현되지 않았다.

## 판정 기준

| 판정 | 뜻 |
|---|---|
| 있음 | 현재 main 코드에 사용자 경로와 저장 또는 결과 반영까지 존재한다 |
| 부분 | 화면, 저장, 렌더 중 일부만 있거나 v71과 조작 방식이 다르다 |
| 없음 | 현재 main 코드에 해당 사용자 기능이 없다 |

근거 행 번호는 이 브랜치가 기준으로 삼은 `origin/main` 이후 현재 파일의 줄 번호다. 운영 화면에서의 실제 재생 성공은 아직 관찰되지 않았으므로, 코드가 있어도 운영 실측은 별도 표기한다.
